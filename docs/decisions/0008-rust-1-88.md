# 0008 — Rust 1.88 minimum

**Contexte.** Avec `rust-version = "1.85"`, Cargo choisit les versions de
dépendances compatibles avec 1.85, dont `time` 0.3.45, touchée par l'avis
RustSec sur l'analyse RFC 2822. Le code utilise aussi les `let` chaînés,
stables depuis 1.88.

**Décision.** `rust-version = "1.88"` dans le workspace.

**Conséquences.** `cargo deny check` passe. La CI utilise la dernière version
stable ; la version minimale n'est pas testée séparément.
